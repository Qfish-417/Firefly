# 公文智能仿真系统｜AI Agent + 文档自动化

**项目角色：核心开发 / Agent 工作流设计**　　**项目周期：2026.06—2026.08**

## 项目简介

面向党政机关公文起草、仿写与格式导出的智能化系统。用户输入口语素材或上传 Word 文档，系统通过大模型完成内容生成、润色和结构识别，再由确定性文档引擎套用上报文、下发文、电文、函等格式模板，最终导出可直接流转的 DOCX，并提供 PDF 预览与分页校验。

## 核心工作

- 设计“需求解析 → 内容生成/润色 → 文档结构识别 → 模板渲染 → DOCX/PDF 校验 → 结果修正”的 Agent 化工作流，将模型负责的语义任务与规则引擎负责的版式任务解耦，降低模型输出不稳定对正式公文格式的影响。
- 基于 Spring Boot、WebFlux 和 OpenAI 兼容接口接入内网 vLLM/Qwen 模型，实现正文生成、续写、扩写、缩写、改写、润色及上传文档段落角色识别；通过 SSE 流式返回生成结果，改善长文本交互体验。
- 使用 React、TypeScript、Tiptap 构建富文本编辑器，支持模板切换、段落级操作、附件编辑、格式预览和 DOCX 导出；补充前端分页高度测量，使版记能够稳定落在下一偶数页。
- 基于 Apache POI/XWPF、Jsoup、PDFBox 和 LibreOffice 搭建文档处理链路：解析 HTML/Word 内容、识别标题/主送机关/正文/附件/落款等角色，按模板重建段落、字体、行距、页边距、横线和页码。
- 针对“预览与下载分页不一致、头部横线重复、浮动对象遮挡文字、发电单位/等级行错位”等问题建立坐标化验证流程，直接解析 DOCX XML 与 PDF 文本坐标进行回归校验，避免仅凭截图调整样式。
- 完成 Docker Compose 部署，拆分 Nginx 静态资源层与 Spring Boot 服务层，接入服务器内网模型服务；发布包不携带真实密钥，通过环境变量配置模型地址，支持离线复用已有镜像启动。

## 项目结果

- 覆盖 4 类公文模板及附件、版记、页码等复杂场景，形成统一的上传、编辑、预览、下载链路。
- 将文档格式修正从“手工调样式”变为“模板约束 + 坐标验证 + 自动回归”，显著降低反复人工排版成本。
- 解决上报文/下发文版记跨页、偶数页补白、页码起始值错误等问题；电文头部文字、横线、标题和主送机关按模板坐标校准。
- 形成可复用的 Agent 任务拆解方式：模型只处理语义和结构判断，最终字体、行距、分页和文件输出由可测试的确定性代码执行。
