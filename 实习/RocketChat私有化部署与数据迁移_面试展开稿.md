# Rocket.Chat 私有化部署与数据迁移 —— 面试展开稿（STAR）

## 情境（Situation）

教育系统长期运行 Rocket.Chat 3.18.2，积累约 6.3 万用户、6.5 万房间、66 万消息。需要将系统迁移升级到 6.13.0，并部署到新的服务器集群（应用与数据库分离），同时接入统一域名与 SSL 证书体系；新环境为内网，必须离线部署。

## 任务（Task）

在不影响数据完整性的前提下，完成跨大版本迁移与多服务器私有化部署，并解决迁移后出现的访问白屏、跨域、WebSocket 重连等一系列问题。

## 行动（Action）

- 设计 3.18.2 → 4.8.7 → 5.4.10 → 6.13.0 的分级迁移链，避免直接跨大版本导致迁移版本不兼容，全程未篡改迁移版本号。
- 部署 MongoDB 单节点副本集并修正成员发布地址，完成 MongoDB 5.0 → 6.0 的 FCV 升级。
- 用 docker save/load 打包镜像实现离线分发，用 rsync 断点续传解决 23GB 快照传输中断问题。
- 配置 Nginx HTTPS 与 WebSocket 升级头，用 openssl 校验通配证书链与私钥匹配。
- 针对白屏 / 跨域 / WebSocket 重连，用 curl、openssl、nc、telnet 逐层排查，最终定位到 WAF / 零信任网关对静态资源与长连接的拦截，并与网络管理员协作推动解决。

## 结果（Result）

- 130 万+ 文档零失败迁移，Rocket.Chat 6.13.0 私有化部署成功。
- 解决 10+ 项部署与网络问题，形成“服务器侧 vs 网络侧”分层排查方法论。
- 产出可离线部署的镜像包与脚本，可复用于其它环境，显著降低后续迁移成本。
